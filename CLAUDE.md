# route-mapper

Lightweight PHP routing library (`yeremi/route-mapper`, PHP ^8.0). Used by `wp-ingresso`.

## Commands
- `composer test` — PHPUnit
- `composer phpstan` — PHPStan
- `composer cs-check` / `composer cs-fix` — php-cs-fixer

Run all three checks before finishing. CI tests PHP 8.0–8.5, so don't use syntax newer than 8.0. Releases are automated by semantic-release from Conventional Commits — don't edit versions or `CHANGELOG.md` by hand.
